  IMPLEMENTATION GUIDE

OAuth 2.0 Flow

Simple, secure, and standards-compliant authentication pipeline

1

Initiate Auth

Redirect users to NM Auth with client credentials and callback URL.

GET /nm-auth
?client_id=XXX
&redirect_uri=https://app.com/callback
2

User Sign-In

User authenticates securely through NM Auth UI with credentials.

User enters credentials
Grants permission
NM Auth validates
3

Authorization Code

Receive short-lived authorization code for secure token exchange.

GET /callback
?code=AUTH_CODE_123
&state=xyz
4

Token Exchange

Exchange authorization code for access and ID tokens securely.

POST /token
{code, client_id,
client_secret}
5

Receive Tokens

Get signed access token, ID token, and refresh token for your app.

{access_token,
id_token,
token_type: Bearer}
6

Fetch User Data

Use access token to retrieve user profile from userinfo endpoint.

GET /userinfo
Authorization:
Bearer TOKEN
